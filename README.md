# Single-Page CV

A single-page CV built with HTML and internal CSS.

## Project Description

This project is part of the Roadmap.sh Single-Page CV project.
It demonstrates basic HTML structure, semantic HTML, and meta tags.

## Technologies Used

- HTML5
- Internal CSS

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
